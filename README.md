# 💳 Credit Card Fraud Detection using Machine Learning

## 📌 Project Overview

This project focuses on detecting fraudulent credit card transactions using Machine Learning.

The system analyzes transaction-related features and predicts whether a transaction is **legitimate** or **fraudulent**.

The main goal of this project is to build a machine learning solution that can help identify suspicious transactions and reduce financial fraud.

---

## 🎯 Objectives

- Detect fraudulent credit card transactions.
- Perform data preprocessing and exploratory data analysis.
- Handle class imbalance in the dataset.
- Train and evaluate machine learning models.
- Compare model performance using appropriate evaluation metrics.
- Build an easy-to-use prediction application using Streamlit.
